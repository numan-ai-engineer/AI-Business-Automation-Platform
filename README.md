# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/numan-ai-engineer/AI-Business-Automation-Platform.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
```

Run backend server:

```bash
npm start
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
